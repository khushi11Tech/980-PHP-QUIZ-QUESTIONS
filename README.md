## Project Objective
The objective of this project is to develop a simple 10-question
MCQ Quiz System using PHP. The system allows the user to answer
questions and displays the score, percentage and performance.

## Features
- 10 PHP multiple-choice questions
- One quiz form
- Automatic score calculation
- Percentage calculation
- Performance result
- Simple and user-friendly design
- No database used

## Algorithm
1. Start the program.
2. Store 10 questions and their options in PHP arrays.
3. Display all questions using an HTML form.
4. Take the answers submitted by the user.
5. Compare the selected answers with the correct answers.
6. Calculate the total score.
7. Calculate the percentage.
8. Display the final performance.
9. Stop the program.

 Technologies Used
- HTML
- CSS
- PHP

 Steps to Run
1. Install XAMPP.
2. Start Apache from XAMPP Control Panel.
3. Place the project folder inside the htdocs folder.
4. Open a web browser.
5. Enter http:localhost/php5th/index.php.
6. Answer all the questions and click Submit Quiz.

Project Files
- index.php – Contains the PHP quiz questions and logic.
- style.css – Contains the design and styling of the quiz.
